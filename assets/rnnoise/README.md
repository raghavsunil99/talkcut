# RNNoise model

`sh.rnnn` is the "somnolent-hogwash" model (2018-09-01) from
https://github.com/GregorR/rnnoise-models, trained for speech in recording noise. ffmpeg's
`arnndn` filter reads it for Studio Sound.

That repository states that, apart from its tools and README, its contents are "not creative
and thus none of it is subject to copyright". The file is used unchanged.

`scripts/bench-sound.js` compares it with the other chains.
